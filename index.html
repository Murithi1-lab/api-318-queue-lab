Try a decision, then predict the result

  1. Reduce check-in service time. Does the security queue improve, or do passengers reach it faster?
  2. Add one security lane. Compare waiting and resource cost using the same seed.
  3. Keep the mean rates fixed and switch from fixed to exponential timing. Watch queues form.
  4. Turn on a flight-bank surge. Does enough daily capacity guarantee enough capacity at the peak?

Use the same seed and settings for reproducible comparisons. Changing service distributions changes their variability; one finite run can still give an unexpected ordering.

Model assumptions, validation, and connection to the reading

This is a simplified departure-only network, with pooled first-come-first-served queues feeding multiple parallel check-in desks and security lanes. Arrivals enter during a finite window. Exponential mode uses Poisson arrivals; uniform mode uses inter-arrivals and services uniformly distributed from 0.5 to 1.5 times their means. Fixed mode uses constant durations. Walking times are deterministic and passenger-independent. Flight passengers arrive independently and uniformly within their specified arrival intervals, regardless of the background timing distribution. Flight groups then mix into the same pooled queues. The airport selector changes the schematic, not the demand or staffing. This planner models departure passengers, not arriving-aircraft unloading. Gate assignment is illustrative; no calibrated airline schedule, baggage system, immigration, boarding cutoff, or missed-flight prediction is modeled.

A desk or lane represents one aggregated service resource, not one employee. Cost assumes every selected resource stays staffed from opening until the later of the arrival-window end or the last security completion. It excludes infrastructure, training, and other airport costs. Staffing changes require building a new run, not opening a lane midway through the animation.

The surge uses a rate multiplier of 1 in the first and last thirds and 2 in the middle third, so expected total arrivals rise by one third. This is additional demand, not merely a redistribution of a fixed passenger total.

For each station, choose the resource with the earliest availability, start at max(station arrival, resource availability), and finish at start plus service duration. Wait is start minus station arrival. Queues count passengers who have reached a station but have not started service. Overflow counts are measured from exact arrival and service-start events, not animation frames.

The airport simulator is inspired by Perez and Fagan's 2015 case, Queuing Theory to the Rescue: Managing Security Screening Lines at Logan Airport. It explores linked queues, limited space, variable demand, and staffing tradeoffs using original schematic graphics and illustrative inputs.
